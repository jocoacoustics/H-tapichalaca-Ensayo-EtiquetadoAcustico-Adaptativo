# Papiro v0.3.2 · GitHub Pages

1. Crea un repositorio público (o de acceso compatible con tu plan) en GitHub.
2. Copia el **contenido interno** de `githubpages/` a la **raíz** del repositorio; no subas la carpeta externa.
3. Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.
4. Abre `https://USUARIO.github.io/REPO/`. En un repositorio llamado `USUARIO.github.io`, abre ese dominio directamente.
5. No necesitas ejecutar el notebook en GitHub Pages: Colab calcula y Pages solo publica.
6. Si el WAV largo se añadió después de crear el ZIP, ejecuta el notebook otra vez y vuelve a subir el contenido regenerado.

**Permisos:** la grabación de referencia BioWeb (PUCE) tiene titularidad ajena. Antes de publicar en un repositorio público, obtén permiso de redistribución; si no lo tienes, retira `assets/audio/bioweb_tapichalaca.mp3` y modifica el reproductor para enlazar BioWeb. El proyecto de investigación privado puede conservarla según los términos aplicables.

La versión pública usa MP3 comprimidos y spectrogramas/calculaciones ya generados, no WAV bruto ni modelos. No afirmamos que los pesos COCO identifiquen ranas.
